How a page earns trust

  1. Plain words. The text uses short sentences and simple words. A reader who knows some code and some algebra can follow it.
  2. Sources. Each claim has a source and a date. The build computes its evidence label: proved, measured here, replicated, reported or contested.
  3. Derivations. Each equation is derived on the page or cited to the exact equation of its source. A Lean proof lets a computer check a theorem.
  4. Tests. Each reference implementation has tests. The PyTorch and JAX versions must agree with the NumPy version. The build runs them in a pinned image.
  5. Honest badges. The build computes each badge from evidence. Nobody writes a badge by hand. Read about the badges.
